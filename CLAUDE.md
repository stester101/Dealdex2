# CLAUDE.md - Deal Dex 2

Read this first. Then `docs/STATUS.md` (what works now) and `docs/SPEC.md` (the agreed plan).

## Hard rules
- Android only. Godot **4.3**, renderer **gl_compatibility**. Base resolution 270 x 600 portrait, `aspect=expand`, integer scaling.
- **No emoji anywhere.** All art is pixel art generated by `tools/*.py` on one palette. Change the generator, then run `python3 tools/build_assets.py`. Do not hand-edit PNGs.
- Text uses the bitmap font (`PixelText`), not Godot fonts.
- Bluetooth controllers and Flip "Flex mode" are **out of scope** (owner's decision).
- Keep the in-jokes from Deal Dex 1 (friend group: Kettle, Oli, etc.).
- Write user-facing docs in plain, short sentences (ASD-STE100 style).

## Layout
- `src/main.gd` - root: layers, dialog/choice, fades, battle launch, CI self-test (`-- --selftest`).
- `src/game.gd` (autoload `Game`) - state, strain maths, save/load (`user://save.json`).
- `src/data.gd` (autoload `Data`) - types, moves, strains, items, props.
- `src/audio.gd` (autoload `Sfx`).
- `src/world/` - `world.gd` (map build, movement, NPCs, lights), `maps.gd` (ASCII maps, trainers), `story.gd` (scripts), `actor.gd`.
- `src/battle/battle.gd` - battles.
- `src/ui/` - `pixel_text.gd`, `dialog_box.gd`, `choice_box.gd`, `touch_panel.gd`, `menus.gd`, `ui.gd`.
- `src/shaders/` - water, flash, transition.

## GDScript conventions
- Use `var x = ...` or an explicit type (`var x: int = ...`). Avoid `:=` on Dictionary/Variant values (inference error).
- Event handlers take an untyped `ev`.
- Await-based flow: `await Game.main.say([...], "NAME")`, `await Game.main.ask("?")`, `await Game.main.start_battle(cfg)`.

## CI
- `.github/workflows/build.yml`: imports, runs the headless self-test, exports a debug APK, publishes a Release, and pushes logs to the `ci-logs` branch.
- To read CI results without GitHub API access: `git fetch origin ci-logs && git show origin/ci-logs:selftest.log`.
